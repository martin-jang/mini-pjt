# DESIGN.md — Legacy2Next 콘솔 디자인 규칙 (v2)

Stitch 프로젝트 `Legacy2Next-console` (`projects/226818788639833589`), 디자인 시스템 `Legacy2Next Console` (`assets/ca48bd0ce8444d3fb59ed90c340280d9`).
화면 원본: `screens/*.html` (Stitch 생성 HTML, 저장 시 수정 사항은 아래 "저장 시 손본 것"), `screens/*.png` (로컬 렌더링, 1440px 폭).
이전 버전(v1, 모노톤 zinc)은 `archive/v1-mono/`에 보관.

## 출처

[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)의 Vercel DESIGN.md를 레퍼런스로 삼아, 콘솔(앱 화면)에 맞게 고친 버전이다. Stitch에 올린 원본은 `reference/stitch-design-system.md`.

- 가져온 것: 잉크 블랙 + 회색 단계, 1px 헤어라인, Geist 폰트, 음수 자간, 굵기 600 상한, 상태 색 체계
- 버린 것: 메시 그라데이션(브랜드 고유), 100px 알약 버튼, 장식용 영문 모노 라벨
- 추가한 것: 한글 폰트, 단계별 상태 색, AI 디자인 패턴 금지 목록

## 톤

성숙한 배포 대시보드처럼 조용하고 정보 중심. 거의 흰 배경 위 흰 카드(1px 헤어라인), 잉크 블랙 글자, 화면당 검은 주요 버튼 하나. **색은 상태를 알릴 때만** 쓴다. 그라데이션·발광·무거운 그림자 없음.

## 컴포넌트 규칙

- **주요 버튼**: `ink` 배경 + 흰 글자, 높이 36px. 화면당 하나
- **보조 버튼**: 흰 배경 + `hairline` 테두리 + `ink` 글자. 위험 동작(반려·실행 중단)은 글자만 `error`
- **상태 배지**: 흰 배경 + `hairline` 테두리 + 작은 상태 점 + 한국어 라벨. 승인 대기 배지만 `warning` 연한 배경 허용
- **라디오 카드**: 선택은 1px `ink` 테두리, 미선택은 `hairline`. 설명 13px, 선택 `body` / 미선택 `mute`
- **안내 배너**: 상태 연한 배경 + 왼쪽 2px 상태 색 테두리만
- **로그 뷰어**: `ink` 배경, `#ededed` 글자, Geist Mono 13px. 경고 줄은 왼쪽 2px `warning` 테두리
- **표**: 머리글 12px `mute`, 행 구분 `hairline`. 상태는 점 + 한국어

## 레이아웃

- 좌측 사이드바 240px (`canvas-soft`, 오른쪽 헤어라인): 로고 마크(L2N) + Legacy2Next → "+ 새 요청" → "사이트" 목록(이름 + 상태 점 + 회색 상태어) → 하단 "질의". 활성 행은 `canvas-soft-2` 배경
- 상단 바 56px 흰색: 왼쪽 breadcrumb, 오른쪽 아바타 아이콘. 그 외 아무것도 두지 않는다
- 본문: 폼 화면 720~880px, 대시보드 화면 1120px, 질의 760px. 제목 위 48px, 섹션 사이 32px
- 카드 안에 카드를 넣지 않는다. 여백과 구분선으로 나눈다

## 저장 시 손본 것 (Stitch 원본과 다른 점)

- 01: Tailwind `fontFamily` 설정이 문자열 하나로 깨져 있어 배열로 고침, 사이드바 "질의" 아이콘이 글자로 보이던 것 수정
- 02: 로그·아바타의 사용자 이름 제거
- 03~06: 아바타 이니셜 → 사람 아이콘, 로고 마크(L2N) 없는 화면에 추가, 사이드바 상태어 색을 `mute`로 통일
- 04: 사이드바 승인 대기 점이 v1 색(`#b8904f`)이던 것 `#f5a623`으로, 예시 계좌번호 마스킹, 예시 이름·"FaceID"·"ActiveX" 문구 제거, 상세 경로 `/transfer/direct` → `/transfer`
- 04 PNG: 하단 고정 바가 전체 캡처에서 본문에 겹쳐 PNG만 고정 해제 후 촬영

## 구현 시 바로잡을 것

**레이아웃·구성·톤만 따르고** 아래는 T02 구현 때 맞춘다.

- 화면마다 마크업 방식이 다르다(01 Tailwind 토큰, 02·03 순수 CSS, 04~06 Tailwind 임의값). 사이드바 로고 크기·패딩·글자 크기도 조금씩 다르다 → 위 토큰 표와 공통 레이아웃 컴포넌트 하나로 통일
- 단계 번호 표기 통일: 01은 원 안 숫자, 02는 ①~⑤
- 02 가드레일 "규칙" 열이 모노 폰트 → 일반 폰트 (G 번호만 모노 허용)
- 02 로그 예시 중 "API 명세 추출 … REST 엔드포인트 18개", "AST 토큰 치환 및 반응형 레이아웃 정렬"은 실제 에이전트 이벤트가 아님 → SSE 이벤트 정의대로. 디자인 시스템 생성 로그가 승인 1보다 먼저 찍힌 순서도 바로잡기
- 03 "사이트 성격"만 제목이 카드 안에 있음 → 다른 섹션처럼 카드 밖
- 04 썸네일은 장식용 목업 → 실제 Stitch 스크린샷으로
- 예시 값(사이트명, 화면명, 경로, 숫자)은 전부 API 응답으로 대체. 하드코딩 금지 (CLAUDE.md 공통 규칙)
