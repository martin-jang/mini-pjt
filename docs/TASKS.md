# TASKS.md — 작업 목록

**진행 방식**: 콘솔 UI를 먼저 만들어 시스템 전체 흐름을 화면으로 확인하고, 그 위에 기능을 하나씩 붙인다. 기능 작업(T05~)은 "콘솔에서 결과가 보인다"를 완료 기준에 포함한다.

작업 하나가 끝날 때마다 결과를 보고하고 확인받은 뒤 다음으로 넘어간다 (CLAUDE.md 작업 방식). 상태: ⬜ 대기 · 🔄 진행 · ✅ 완료

## 1단계: 콘솔 UI 먼저 (목업 데이터)

| ID | 작업 | 완료 기준 | 상태 |
|---|---|---|---|
| T01 | 콘솔 UI 디자인: Stitch로 5개 화면(요청·진행·승인·결과·질의) | `ui/design/`에 저장, 사용자 승인 | ✅ |
| T02 | 콘솔 UI 구현(목업): 5개 화면, 가짜 API·가짜 SSE로 전체 흐름(요청 → 단계 진행 → 분석 리뷰 승인 → 디자인 확인 → 결과)을 재현 | 콘솔만으로 시스템 흐름을 처음부터 끝까지 클릭해 볼 수 있다 | ✅ |
