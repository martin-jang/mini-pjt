# T06 · 합성 변이 픽스처 + L2 정답 라벨

- **예상**: 60분 · **일정**: Day 9 점심 전후 · **의존**: T05
- **관련**: `SERVICE.md` "변이 전제와 데모 대상" (결정 D12), §5 L2 지표

## 목표
스냅샷 화면을 복제해 변이를 **의도적으로 주입**하고, 주입 목록을 그대로 L2 정답 라벨로 씁니다. 정답이 분석 결과에 끌려가지 않게 하기 위함입니다.

## 작업
- [ ] `scripts/make_fixtures.py`: 스냅샷 화면 4~6개를 복제해 변이 주입
  - 라벨 변이: 검색 버튼 "조회/검색/Find/Go"
  - 형식 변이: 날짜 `YYYY-MM-DD` / `MM/DD/YYYY` / `YYYYMMDD`, 금액 표기
  - 레이아웃 변이: 조회조건 위치(그리드 위/왼쪽)
  - **업무 의미가 있는 차이**(변형 유지 정답): 특정 화면에만 확인 단계, 특정 목록에만 합계 행
- [ ] 모든 픽스처에 "교육용 더미 데이터" 표기
- [ ] `evaluation/golden/` 정답 파일
  - `screens.json`: 화면 목록 (스냅샷 + 픽스처)
  - `fields.json`: 화면별 필드
  - `variant_groups.json`: 주입한 변이 그룹
  - `unification_labels.json`: 그룹별 기대 결정(통일/변형 유지/보류)

## 산출물
`data/fixtures/`, `scripts/make_fixtures.py`, `evaluation/golden/*.json`

## 완료 기준
- 변이 그룹 5개 이상, 그중 "변형 유지" 정답 2개 이상
- 정답 파일이 스크립트의 주입 목록에서 자동 생성됨 (손으로 결과를 보고 쓰지 않음)

## 줄일 수 있는 부분
- 화면 수를 4개로, 변이 그룹을 5개로 최소화
